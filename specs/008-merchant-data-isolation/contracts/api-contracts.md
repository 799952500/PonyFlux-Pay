# Contracts: 商户数据隔离治理

## 统一约定

所有后台接口保持统一业务响应结构：

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

跨商户访问被拒绝时，响应不得暴露目标数据是否存在、所属商户、敏感字段或内部查询条件。

## 数据范围契约

### 商户管理员访问商户级数据

**Actor**: 商户管理员  
**Scope Rule**: 服务端必须根据登录身份自动限定到授权商户范围。  
**Input Rule**: 请求中的 `merchantId`、资源标识、批量 ID、导出条件和统计条件只能缩小范围，不能扩大授权范围。  
**Output Rule**: 列表、详情、统计、导出和批量结果不得包含授权范围外数据。

**Acceptance Contract**:
- 授权范围内资源返回正常业务结果。
- 授权范围外资源返回拒绝或空结果。
- 批量请求中混入授权范围外资源时，授权外资源不得被处理。

### 系统管理员访问商户级数据

**Actor**: 系统管理员  
**Scope Rule**: 可在平台授权范围内按商户筛选、审计和治理。  
**Input Rule**: 可使用商户筛选条件查看指定商户或全局治理视图。  
**Output Rule**: 结果必须明确展示商户归属，避免跨商户混淆。

## 隔离检查结果契约

### 查询数据隔离检查结果

**Purpose**: 展示各数据类别和功能入口的隔离状态。

**Request Parameters**:
- `classification`: 商户级 / 全局级 / 系统审计 / 待人工确认
- `riskLevel`: 高 / 中 / 低
- `remediationStatus`: 待处理 / 处理中 / 已完成 / 已豁免 / 需人工确认
- `targetType`: 数据表 / 页面 / 接口 / 异步任务 / 导出任务
- `merchantId`: 系统管理员可选；商户管理员仅限授权范围
- `page` / `size`: 分页参数

**Response Data**:
- `items[]`: 检查项列表
  - `checkId`
  - `targetType`
  - `targetName`
  - `classification`
  - `merchantFieldStatus`
  - `riskLevel`
  - `affectedEntries`
  - `remediationStatus`
  - `decisionReason`
- `total`: 总数

## 全局配置访问契约

### 访问全局配置

**Actor**: 系统管理员或被授权商户管理员  
**Scope Rule**: 全局配置不强制绑定单一商户，但输出必须避免泄露商户专属敏感信息。  
**Output Rule**: 商户管理员只能看到可用选项、状态或脱敏摘要；系统管理员可按权限维护。

**Acceptance Contract**:
- 公共字典、基础渠道类型、通用菜单等可保持全局共享。
- 商户专属密钥、账号、费率、回调配置必须按商户级数据处理。

## 审计反馈契约

### 记录关键操作审计

**Trigger Actions**:
- 查看敏感详情
- 创建、更新、删除商户级配置
- 审核、退款、补单、对账差异处理
- 导出商户级数据
- 跨商户访问拒绝

**Audit Data**:
- 操作者和操作者类型
- 操作资源类型和资源标识
- 涉及商户
- 操作动作和结果
- 操作时间
- 脱敏来源信息

**Acceptance Contract**:
- 系统管理员可在 3 分钟内定位任一商户级数据的商户归属、风险状态和最近关键操作记录。
- 审计结果不得包含未脱敏密钥、证书、密码或完整敏感信息。

## 验收入口矩阵

| 入口类别 | 商户管理员期望 | 系统管理员期望 |
|----------|----------------|----------------|
| 列表查询 | 只返回授权商户数据 | 可按商户筛选并展示归属 |
| 详情查询 | 授权外拒绝或不可见 | 授权范围内可查看 |
| 统计看板 | 只统计授权商户数据 | 可跨商户或按商户统计 |
| 导出任务 | 只导出授权商户数据 | 可按授权范围导出 |
| 批量操作 | 授权外资源不处理 | 授权范围内可处理 |
| 异步任务 | 使用任务所属商户限制 | 可治理任务范围 |
| 全局配置 | 只看允许的共享信息 | 可维护全局配置 |
