# 商户数据隔离验收设计

**Feature**: 008-merchant-data-isolation  
**Purpose**: 定义 Demo 多商户验收数据、隔离路径、跨商户拒绝、安全审计和日志闭环记录方式。

## 验收账号与商户样本

| 账号 | 角色 | 授权商户范围 | 预期能力 |
|------|------|--------------|----------|
| `admin` / `admin123` | `SUPER_ADMIN` | 平台全局 | 可跨商户筛选、治理隔离检查项、维护全局配置 |
| `merchant_m100001` / `admin123` | 商户管理员 | `M100001` 星云零售旗舰店 | 只能查看和操作 M100001 的订单、支付、退款、路由、费率、风控和审计摘要 |
| `merchant_m100002` / `admin123` | 商户管理员 | `M100002` 蓝海餐饮连锁 | 只能查看和操作 M100002 的资源 |
| `finance_demo` / `admin123` | 财务演示 | `M100001` | 验证既有限定商户账号兼容性 |
| `risk_demo` / `admin123` | 风控演示 | 平台风控视角 | 验证系统审计与风控入口，不作为普通商户管理员验收基准 |

## 商户管理员验收路径

### M100001 管理员

1. 登录 `merchant_m100001`。
2. 访问订单、支付、退款、渠道账号、渠道路由、对账、风控、仪表盘、导出入口。
3. 确认列表和统计只出现 `M100001` 数据。
4. 使用 `M100002` 资源标识访问：
   - 订单详情：`ORD-20260518-0003`
   - 支付记录：`PAY-20260518-002`
   - 退款审核：`REF-20260517-001`
   - 渠道路由：`admin_channel_routes.id=3`
5. 预期返回通用拒绝、空结果或不可操作状态，不展示目标商户名称、归属字段、金额明细或存在性。
6. 创建导出任务，确认导出文件只包含 `M100001` 数据。

### M100002 管理员

1. 登录 `merchant_m100002`。
2. 重复订单、退款、路由、风控和导出验证。
3. 使用 `M100001` 资源标识访问：
   - 订单详情：`ORD-20260518-0001`
   - 退款：`REF-20260518-001`
   - 路由：`admin_channel_routes.id=1`
4. 预期与 M100001 管理员一致，不泄露目标资源是否存在。

## 系统管理员验收路径

1. 登录 `admin`。
2. 打开数据隔离治理页面，查看检查项列表。
3. 按 `classification`、`riskLevel`、`remediationStatus`、`targetType`、`merchantId` 筛选。
4. 查看订单、退款、对账、风控、费率、审计日志入口，确认可按商户筛选并展示商户归属。
5. 查看系统配置、基础渠道、支付方式公共定义，确认标识为全局级或脱敏摘要。
6. 对待人工确认项执行：标记处理中、补充归属、豁免或完成整改。

## 存量缺口验收路径

| 缺口目标 | 当前问题 | 预期处理 |

| `recon_task` | 缺少直接 `merchant_id` | 补充商户任务归属或通过账号/订单推断；未确认前商户管理员不可见 |
| `recon_bill_record` | 缺少直接 `merchant_id` | 通过 `task_id` 与 `out_trade_no` 推断，失败则待人工确认 |

## 安全复核清单

- [ ] 所有商户级列表、详情、统计、导出、批量和异步入口均由服务端授权范围限制。
- [ ] 请求参数 `merchantId`、批量 ID、导出条件只能缩小范围，不能扩大范围。
- [ ] 跨商户拒绝响应不包含目标商户名、资源金额、状态、内部 SQL 条件或存在性提示。
- [ ] 系统管理员入口展示商户归属，避免跨商户混淆。
- [ ] 全局配置已给出白名单或豁免理由，敏感配置输出脱敏。
- [ ] 待人工确认数据在处理完成前不向普通商户管理员开放。
- [ ] Playwright 验证期间 admin-server、cashier-server、recon-server 日志无阻断错误。
